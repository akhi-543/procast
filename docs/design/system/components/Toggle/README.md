A 36 × 20 on/off switch for Settings.

**You provide:** whether it is on, and a label beside it.

- Off: surface_strong track, text_muted knob, on the left. On: accent track, accent_text knob, on the right. Position and fill both change, so it never depends on colour alone.
- The change is immediate: no slide. The setting applies at once, with no Save step.
- Use it for a setting that is on or off. For one of a few options use SegmentedControl.
