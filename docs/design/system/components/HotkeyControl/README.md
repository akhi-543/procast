The one hotkey control: a Field holding the keys as KeyCaps, or an invitation to record them.

**You provide:** the current hotkey (may be empty) and whether it is recording.

- Set: the keys as caps. Empty: a keyboard icon and "Record" in text_muted.
- Recording: the Field's focus border and ring, and the line "Press keys. Backspace removes, Esc cancels".
- A conflict is reported in the Settings footer with a danger dot, not inside the control.
